# เว็บไซต์ขายรถยนต์ ORD RAPTER

เว็บไซต์นี้ถูกสร้างขึ้นเพื่อเป็นแคตตาล็อกออนไลน์สำหรับแสดงข้อมูลรถยนต์หลากหลายประเภท พร้อมรายละเอียดและโปรโมชันพิเศษต่าง ๆ

**คำขวัญ:** ซิ่งได้ทุกที่ ซี่ได้ทุกท่า

### คุณสมบัติหลัก

* **หน้าแรก (Homepage):** นำเสนอแบนเนอร์ต้อนรับ, ข้อมูลโปรโมชันล่าสุด, และลิสต์รถยนต์ทั้งหมดที่มีให้เลือกซื้อ
* **หน้ารายละเอียดรถ:** เมื่อคลิกที่รถแต่ละคัน จะแสดงข้อมูลเฉพาะของรถรุ่นนั้น ๆ เช่น เครื่องยนต์, เกียร์, และระบบความปลอดภัย
* **หน้าติดต่อ:** มีปุ่มสำหรับติดต่อสอบถามข้อมูลเพิ่มเติมผ่านทาง Instagram โดยตรง

### โครงสร้างไฟล์

* `ord rapter.html`: ไฟล์หน้าแรกของเว็บไซต์
* `car-detail.html`, `car-detail2.html`, ...: ไฟล์สำหรับหน้ารายละเอียดรถแต่ละคัน
* `หน้าติดต่อ.html`: ไฟล์หน้าสำหรับข้อมูลการติดต่อ
* `img/`: โฟลเดอร์สำหรับเก็บรูปภาพทั้งหมดที่ใช้ในเว็บไซต์ เช่น รูปแบนเนอร์และรูปภาพรถยนต์

### วิธีการเปิดใช้งาน

คุณสามารถเปิดไฟล์ `ord rapter.html` ด้วยเว็บเบราว์เซอร์ (เช่น Google Chrome, Firefox, หรือ Safari) เพื่อดูเว็บไซต์ได้ทันที
