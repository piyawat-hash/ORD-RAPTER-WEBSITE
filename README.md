# ORD RAPTER - เว็บไซต์แคตตาล็อกรถยนต์

เว็บไซต์นี้ถูกพัฒนาขึ้นเพื่อเป็นแพลตฟอร์มออนไลน์สำหรับแสดงข้อมูลรถยนต์คุณภาพสูงของ **ORD RAPTER** ที่มาพร้อมกับรายละเอียดครบถ้วนและใช้งานง่ายสำหรับลูกค้า

## ภาพรวมของโปรเจกต์

* **วัตถุประสงค์:** เพื่อสร้างแคตตาล็อกรถยนต์ดิจิทัลที่เข้าถึงง่ายและให้ข้อมูลที่จำเป็นครบถ้วนสำหรับผู้ที่สนใจ
* **กลุ่มเป้าหมาย:** ผู้ที่กำลังมองหารถยนต์ใหม่หรือรถยนต์มือสองคุณภาพดี

## คุณสมบัติหลัก

* **หน้าแรก (`ord rapter.html`):** แสดงรถยนต์ทั้งหมดในรูปแบบ Grid ที่ดูสวยงาม พร้อมข้อมูลราคาและปีที่ผลิต
* **หน้ารายละเอียด (`car-detail.html`):** แต่ละรุ่นมีหน้าของตัวเองสำหรับแสดงข้อมูลเชิงลึก, รูปภาพขนาดใหญ่, และรายละเอียดทางเทคนิค
* **หน้าติดต่อ (`หน้าติดต่อ.html`):** ลูกค้าสามารถกดปุ่มเพื่อติดต่อสอบถามเพิ่มเติมได้ทันทีผ่านลิงก์ Instagram

## วิธีการใช้งาน

1.  **ดาวน์โหลด Repository:** Clone หรือดาวน์โหลดไฟล์ทั้งหมดจาก GitHub
2.  **เปิดไฟล์:** เปิดไฟล์ `ord rapter.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ เช่น Chrome, Firefox, หรือ Safari
3.  **ใช้งาน:** คุณสามารถคลิกที่รูปภาพรถยนต์เพื่อดูรายละเอียดเพิ่มเติม หรือไปที่หน้าติดต่อเพื่อสอบถามข้อมูล
